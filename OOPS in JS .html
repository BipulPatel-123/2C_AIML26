//Class is a blueprint for creating objects. It encapsulates data for the object and methods to manipulate that data.
//objects are instances of classes. They can have properties and methods that define their behavior.
//constructor is a special method for creating and initializing an object created with a class. It is called when an instance of the class is created.
//Data members are variables that hold data specific to an object. They are defined within a class and can be accessed using the object instance.
//Member functions are functions defined within a class that operate on the data members of the class. They define the behavior of the objects created from the class.
//Inheritance is a mechanism where one class can inherit properties and methods from another class. It allows for code reusability and establishes a relationship between classes.
//static variales and functions are associated with the class itself rather than any particular instance of the class. They can be accessed without creating an instance of the class.
